# Чеклист — какие замки открыты, какие закрыты (Amazfit Active 3 Premium)

Отметка состояния замков по локациям. Локации собраны в пресеты, например «Дом», «Дача», «Офис». На часах вы только переключаете локации «открыто / закрыто». Всё работает без телефона, аккаунты не нужны.

Оформление в стиле watchOS / iOS 26 (Liquid Glass): чёрный фон, стеклянные строки-капсулы, переключатели как в iOS, заголовок со статусом в цветной капсуле. Настройки в Zepp — тёмные сгруппированные карточки, как в «Настройках» iPhone.

## Что умеет

**На часах**
- Сразу открывается пресет по умолчанию: его локации с тумблерами.
- Тап по строке переключает «Открыто» / «Закрыто» (с лёгкой вибрацией). Тумблер включён (зелёный) — закрыто, выключен — открыто.
- Вверху видно, всё ли закрыто: «Всё закрыто» или «Открыто: N из M».
- Кнопка «Пресеты» внизу списка: выбранный там пресет становится пресетом по умолчанию. Свайп вправо или кнопка «назад» возвращают к локациям.

**Карточка быстрого доступа «Чеклист»** (лента карточек: пролистайте вниз → настройки → добавить «Чеклист»)
- Название пресета по умолчанию и сколько локаций открыто и закрыто.
- Тап по карточке открывает приложение.

**На телефоне** (Zepp → Профиль → ваши часы → Приложения → Чеклист → Настройки)
- Создать, переименовать, упорядочить (↑ ↓) и удалить пресеты; удаление пресета — в два нажатия.
- В каждом пресете: добавить, переименовать, упорядочить и удалить локации, переключить «открыто / закрыто» (тумблер включён — закрыто).
- «Сделать основным» — выбрать пресет по умолчанию.

## Синхронизация

Только между часами и телефоном, без интернета и облака.

- **Часы и телефон на связи.** Изменения в Zepp сразу приходят на часы (если приложение на часах открыто — мгновенно, иначе при следующем открытии), переключения на часах сразу уходят на телефон.
- **Связь пропадала** (например, телефон был выключен). Часы запоминают, что вы переключили, и отправляют это, когда связь вернётся: сразу, если приложение на часах открыто, иначе при следующем открытии. Для одной и той же локации (и для выбора пресета по умолчанию) всегда побеждают часы, даже если в Zepp успели поменять её позже, до открытия приложения на часах. Остальные правки из Zepp сохраняются.
- Пока приложение на часах не открыли после возвращения связи, в Zepp видно состояние до перерыва.
- Если данные на телефоне пропали (переустановили Zepp, новый телефон), откройте «Чеклист» на часах: пресеты с часов вернутся в Zepp и объединятся с тем, что вы успели создать заново.

## Установка (один раз, с компьютера)

1. Установите [Node.js](https://nodejs.org) (LTS).
2. В терминале:
   ```
   npm i -g @zeppos/zeus-cli
   cd checklist
   npm install
   zeus login
   ```
   `zeus login` откроет браузер. Войдите тем же аккаунтом Zepp, что и на телефоне.
3. Включите режим разработчика в приложении Zepp на телефоне: **Профиль → Настройки → О приложении**, 7 раз нажмите на логотип Zepp.
4. На компьютере выполните `zeus preview` и выберите **Amazfit Active 3 Premium**. В терминале появится QR-код.
5. На телефоне откройте **Профиль → Настройки → Режим разработчика → Сканировать** и отсканируйте QR-код. Приложение «Чеклист» установится на часы.

App ID приложения (`app.json` → `appId`): 1129163. Не меняйте его после установки: часы посчитают это другим приложением, и данные не перенесутся.

```
setting/index.js         страница настроек в приложении Zepp
app-widget/index.js      карточка быстрого доступа
utils/presets.js         данные и правила синхронизации
utils/watch-store.js     хранилище на часах (общее для приложения и карточки)
assets/gt.r/             иконка, тумблеры, стеклянные элементы (glass/), шрифт Noto Sans Medium (fonts/)
```
